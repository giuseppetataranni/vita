# Vita – la mia app

App personale “tutto in uno” per iPhone (PWA): finanze, calendario, routine, obiettivi, meditazione, note, salute e diario.
Funziona offline, i dati restano sul telefono, nessun costo.

- Installazione passo passo: **GUIDA.md**
- Elenco completo delle funzioni: **FUNZIONALITA.md**

Comandi: `npm install` · `npm run dev` · `npm test` · `npm run build`
